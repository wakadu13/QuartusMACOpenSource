Le livret « Simulation sous Quartus » sur Mac

Ce guide reprend les étapes du livret (§ 14 à 17) et montre comment les faire dans l'application, sans Quartus. L'exemple est celui du livret : le circuit ouex, avec les entrées E1, E2 et la sortie S = E1 ⊕ E2. Il se trouve dans le dossier projets/ouex du dépôt.

§ 14 — Ouvrir un projet (Analysis & Synthesis)

Fichier → Ouvrir un projet ou un fichier Quartus ouvre un .qpf, un .bdf ou un fichier VHDL/Verilog. Le schéma est converti (dossier digital à côté du projet) et les erreurs de câblage ou les blocs introuvables sont signalés à l'ouverture : c'est l'équivalent de Analysis & Synthesis. Si le projet a des numéros de broches, il s'ouvre directement sur la carte DE0 virtuelle.

« Set as Top-Level Entity » : il suffit d'ouvrir le .bdf du bloc à simuler.

§ 15.1 — Créer les signaux d'entrée (fichier .vwf)

Quartus → Éditeur de chronogrammes remplace le Waveform Editor et le Simulator Tool :

  • cliquer sur une case d'une entrée change sa valeur, glisser dessine, Maj+glisser choisit un intervalle ;
  • Horloge…, Compteur…, Valeur…, 0, 1, Inverser s'appliquent à l'entrée choisie (comme Overwrite Clock et Count Value) ;
  • Durée et Grille correspondent à End Time et Grid Size (par exemple 10 ms et 0.5 ms) ;
  • la sortie S est recalculée à chaque modification. Le mode Fonctionnelle est celui du livret ; le mode Temporelle ajoute un délai à chaque porte et montre les retards et les impulsions parasites ;
  • Enregistrer… écrit un fichier .vwf qui s'ouvre aussi dans Quartus.

§ 15.2 — Lancer la simulation

Simulation → Lancer la simulation (ou ▶) : un clic sur une entrée change sa valeur et les sorties suivent aussitôt, les fils à 1 sont en vert clair. Simulation → Exécuter les tests (F11) vérifie la table de vérité de l'élément Test.

§ 16 — Affecter les broches (Pin Planner)

Quartus → Pin Planner montre la carte DE0 : choisir un signal dans la liste puis cliquer sur l'interrupteur, le bouton, la LED ou le segment voulu (ou y glisser le signal). Un bus est placé à partir du bit 0 sur les ressources suivantes. Comme dans le livret : E1 → SW0 (J6), E2 → SW1 (H5), S → LEDG0 (J1).

Afficher sur la carte DE0 ouvre la carte virtuelle : on manipule les interrupteurs et on voit la LED, comme sur la vraie carte.

§ 17 — Programmer le FPGA de la carte DE0

La programmation demande Quartus et la carte en USB : elle se fait sur un PC de l'école. Fichier → Exporter → Exporter vers Quartus (bdf) écrit le schéma et, s'il n'existe pas, le projet Quartus (.qpf, .qsf pour la DE0 avec les broches). Sur le PC : ouvrir le .qpf, compiler, puis Programmer avec le fichier .sof (USB-Blaster, case Program/Configure).

TP auto-corrigés

Un TP donné par l'enseignant contient des tests cachés. Dessinez le circuit, puis Quartus → Vérifier mon TP : la note s'affiche, avec la première ligne fausse quand l'enseignant l'a permis.

Pour les enseignants

Créer un TP : dessinez la solution avec un élément Test (la table de vérité ou les chronogrammes ; dans l'éditeur de chronogrammes, Copier comme test les fournit), puis Quartus → Créer un TP à partir de ce circuit. La copie donnée aux étudiants garde les entrées et sorties, la solution peut être retirée et les tests sont cachés (masqués, pas chiffrés).

Vérifier un dossier : Quartus → Vérifier un dossier de projets Quartus importe et simule tous les projets d'un dossier, par exemple ceux des étudiants, et liste les blocs manquants, les erreurs et les tests qui échouent. En ligne de commande : java -cp Digital.jar CLI quartusCheck -dir dossier -report rapport.md.
